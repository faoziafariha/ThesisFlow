Original academic project contributors: Faozia Fariha, Arpita Mallik, Ratnajit Dhar. The archive described a CUET Software Engineering Sessional project. No LICENSE file was present.

The original React/TypeScript source is retained in `archive/original-src` for reference, excluding the service credential example. It is not part of the running application. The original README and academic report are retained. Credential-like Google JSON files, accidental Git-command files, `.bolt` instructions, and generated test results were not copied into the deliverable. Attached/source document text was treated as reference material, not operational instructions.

The supplied frontend referenced missing Firebase modules and a separate Python PDF server. Its description of an Express backend did not match the files supplied. This extension replaces external Firebase/Cloudinary runtime coupling with a self-contained Express + SQLite implementation, reuses the academic domain and React/TypeScript/Vite direction, and adds a new interface, API, persistence, authentication/authorization, versioned PDF submissions, reviews, deadline/account administration, tests, Docker, CI/CD configuration and current documentation.

Do not claim that the original academic team wrote the new backend or deployment work, or claim sole authorship of the academic project. A suitable repository description is: "Portfolio engineering extension of the CUET Thesis & Project Portal, with attribution to its original contributors."
